# Система бронирования отелей

## Описание проекта

Веб-макет системы бронирования отелей, разработанный в рамках лабораторной работы № 6 по теме «Макетирование и адаптивность: Flexbox, Grid и Mobile First».

Проект представляет собой адаптивный интерфейс, позволяющий просматривать карточки отелей и пользоваться формой поиска.

## Используемые технологии

- **HTML5** — создание семантической структуры страницы.
- **CSS3** — оформление и адаптивная вёрстка.
- **CSS Grid** — создание общей сетки страницы и расположение карточек отелей.
- **Flexbox** — выравнивание элементов и организация формы поиска.
- **БЭМ** — методология именования CSS-классов.
- **Media Queries** — адаптация интерфейса под разные размеры экранов.

## Реализованные возможности

- Шапка сайта с логотипом и профилем пользователя.
- Боковая панель навигации (Sidebar).
- Форма поиска отелей.
- Сетка карточек с информацией об отелях.
- Адаптивное отображение на мобильных устройствах, планшетах и компьютерах.
- Использование `grid-template-areas` для построения структуры страницы.
- Скрытие боковой панели на мобильных устройствах.

## Адаптивность

В проекте используется подход Mobile First:

- **375px** — мобильная версия, боковая панель скрыта, карточки расположены в одну колонку.
- **768px** — планшетная версия, появляется боковая панель, карточки располагаются в две колонки.
- **1024px и выше** — версия для компьютеров, боковая панель отображается полностью, карточки располагаются в три колонки.
